# 聊天历史同步

**免费。把 DeepSeek 账号的网页端和手机 App 聊天记录同步进 DSH，整理成按月份归档、可以继续对话的原生会话。**

## 它解决什么问题

DeepSeek 的聊天记录散在网页和手机 App 里，DSH 里看不到，也不能接着聊。这个插件把同一个账号的聊天记录拉进 DSH，按月份放好，打开就能继续。

## 主要功能

- **一个账号，两端记录**：网页端和手机 App 的聊天都从同一个 DeepSeek 账号读取；支持多个账号
- **只留月份**：DSH 工作区只建月份，不再按分类拆工作区
- **报告和目录**：每次同步生成报告；按主题生成分类目录，每条带 50–100 字摘要
- **只增不减**：同名但内容不同的会话保留；安装前备份；不改 DSH 自建会话
- **免费，不调用模型**：摘要由本地规则生成，零模型费用、零隐私外发；同步本身也不调用模型
- **本机 token**：token 用 Windows DPAPI 加密，界面不显示，不上传

## 安装

要求：Windows 10/11，DSH 0.2.2-rc.3+。

```powershell
dsh plugin add dsh-chat-history-sync
```

安装后打开：

**设置 → 聊天历史同步 → 登录新账号 → 立即同步**

## 数据说明

- 聊天记录只存在本机 DSH 工作区
- 同步时只访问 `chat.deepseek.com`，不发送到其它服务
- token 只存本机，DPAPI 加密
- 无遥测、无统计上报

## 范围

**仅 Windows。** 不是 DeepSeek 官方插件，和 DeepSeek 官方无隶属关系。

## 功能

- **一键同步**：设置页「聊天历史同步」点「立即同步」。进度是**不确定式动画**（不显示假百分比），真实进度以文字显示（引擎逐条回报 `x/y`）。
- **只增不减**：增量合并；数据集里消失的会话默认**保留并报告**，不删除；不触碰 DSH 自建会话。**同名 ≠ 重复**：同名但内容不完全一致的会话一律保留，只有逐字完全一致才按重复处理。
- **可续聊**：同步进来的会话带 `agent-preset/selected`、`model/selection`，打开后可继续对话（已实测）。
- **多账号**：设置页每个账号显示「头像 + 平台昵称」，可编辑「简称」「启用」，可删除；**token 不在界面显示**。简称默认取名称，改名后同步即自动重命名现有会话标题（不需要安装器）。
- **登录新账号**：点「＋ 登录新账号」→ 全新的临时 Edge 配置直接打开登录页（不显示旧账号、无黑框）→ 登录并校验 userId 成功后自动保存 token 到插件数据目录 `.dsh-chat-history-sync/config.json`，未登录/取消不会新增账号；已有账号再次登录会更新资料而不是新增。
- **附件三档**：全部下载 / 只存图片预览 / 都不下载；设置页显示「预计 N 个附件 · X MB」。
- **token 加密**：token 用 Windows DPAPI 加密为 `tokenEnc`，`config.json` 不保存明文；`run-config` 用完即删。
- **每日汇总**：自动同步有变化时，9:00 后只发一条普通通知；可在设置页关闭。
- **每小时自动同步**：定时检查网页端增量；**只在有新增/更新时**生成分类目录、导出、报告与系统通知，无变化时静默。
- **分类目录**：按主题自动分类，作为**报告/目录**交付，不再创建分类工作区；每类超过 9 条自动拆「（续）」。
- **同步报告**：报告追加到同一个「聊天历史同步报告」会话（不新建），正文含分类统计 + 完整目录（账号简称 · 月份 · 标题 + 会话位置链接）；设置页可展开最近报告。
- **自动安装（确认制）**：同步结果有新增/更新时，设置页先出现「检测到新会话 → 现在加入并重启 / 稍后再说」；点「现在加入并重启」才调度安装（约 20 秒后重启 DSH，安装前做进程检查）。没有新增或点「稍后再说」不会重启；状态卡会保留「有会话待安装 / 安装」入口。

## 工作区布局（2026-11-18 迁移后）

- DSH 里只保留**月份工作区**，分类不再建工作区。
- 旧版建的分类工作区会先合并/备份，再退役；`workspace.json` 写前备份。
- `history/ws/<分类>/` 里的参考来源与 PDF 原件**保留**（月份会话里的链接指向它们）。
- 再次安装由内置安装器完成（按月增量、通常数秒）。同步检测到新会话时先出确认卡，点「现在加入并重启」才重启。

## 费用

同步不调用模型，不产生模型费用；仅消耗网络流量（随会话大小与附件策略变化）。

## 账号配置

- 设置 → 聊天历史同步 → 同步账号：编辑名称 / 简称 / 启停 / 删除。
- token 只存在 `.dsh-chat-history-sync/config.json`；新增账号用「登录新账号」流程自动写入。
- `dataset` / `root` 由登录流程自动生成（`history/_raw/conversations.<prefix>.json`、`history/ws-<prefix>`）；正常使用不需要手动配置。
- 简称映射写在 `history/_raw/account-prefixes.json`，安装器按它生成 `[简称]` 标题；数据集文件名保持稳定，改简称不会产生重复数据集。
- 安装器会**动态发现** `history/_raw/conversations.*.json`（任意账号 + 登录新账号），把新账号会话按月合并进月份工作区；沙箱已验证新增账号场景。

## 平台

**仅 Windows**：自动安装/重启使用 schtasks + 隐藏 VBS 启动器，通知使用 Windows Toast，token 使用 Windows DPAPI。macOS/Linux 不在支持范围（不做兼容声明）。
